SVG Charts for SpruceX

Charts that feel like native HTML

Most charting libraries demand weeks of configuration. SpruceX Charts works the opposite way—most of the time, it just works. Define your data, pick a chart type, and you're done.

Read the Docs See Examples
🎯

Declarative by design

No imperative code. No refs. No manually attaching event listeners. Just HTML attributes and SpruceX's reactivity doing the heavy lifting.

📦

Ship less, do more

Tree-shakeable modules mean you import exactly what you use. A basic bar chart adds roughly 12kb to your bundle. That's it.

♿

Accessibility isn't optional

Every chart includes ARIA labels, keyboard navigation, and high-contrast themes. Built to WCAG AA from day one—no retrofitting required.

🖨️

Print-quality vectors

SVG means crisp lines at any zoom. Export to SVG for reports, PNG for sharing, or CSV so your users can work with the raw data.

So, is this the right tool for you?

Use SpruceX Charts if…

  • You're building a SpruceX app and want charts without writing JS
  • You need clean, professional visualizations without fighting a API
  • Bundle size matters to you
  • Accessibility is a requirement, not an afterthought
  • You want zoom, pan, tooltips, and export out of the box
  • You're building dashboards, reports, or admin interfaces

Look elsewhere if…

  • You need to render 10,000+ points in real-time (try Canvas/WebGL)
  • You're not using SpruceX (the declarative syntax depends on it)
  • You need chart types we don't support (chord, force-directed, etc.)
  • You need to support IE11 or browsers without SVG support
  • You want server-rendered chart images (use a dedicated tool for that)
